# Pro Resizer 

An image resizer and compressor that works 100% in the browser. No server uploads, no privacy concerns.
https://shivamyadav121.github.io/image-resizer2/

##  Features
- **Client-Side Processing:** Uses HTML5 Canvas API for instant resizing without data leaving your device.
- **Live Comparison:** Real-time "Before vs After" preview with dynamic file size calculation (KB).
- **Smart Aspect Ratio:** Toggle to maintain original proportions automatically.
- **Multi-Format Support:** Export to JPEG, PNG, or WebP.
- **Theming:** Includes a polished Light/Dark mode toggle with persistent local storage.
- **Pixel-Perfect UI:** Clean, modern interface inspired by professional design tools.

##  Tech Stack
- **HTML5** (Semantic structure)
- **CSS3** (Custom variables, Flexbox/Grid, Dark Mode logic)
- **JavaScript** (Canvas API, FileReader API, Blob handling)

##  How to Use
1. Clone the repository.
2. Open `index.html` in any modern browser.
3. Drag and drop an image, adjust your settings, and hit **Download**.
